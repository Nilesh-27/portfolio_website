# Nilesh Dokuparthi — Portfolio

A responsive, dark-theme portfolio for backend development, cloud engineering, DevOps, and application security roles in Germany. Built with static HTML and CSS; no build step or JavaScript framework is required.

Open `index.html` in a browser. Keep `styles.css` in the same directory.

## Publish with GitHub Pages

### Option A — personal site (recommended)

1. Sign in to GitHub and create a repository named `<YOUR-GITHUB-USERNAME>.github.io` (replace the placeholder with your actual username).
2. Upload `index.html`, `styles.css`, `README.md`, and `.nojekyll` to the repository root.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Wait for the deployment to finish. Your site will be available at `https://<YOUR-GITHUB-USERNAME>.github.io/`.
5. Test the live site and links, then add the URL to LinkedIn **Contact info** and **Featured**.

### Option B — project repository

You can instead create a repository such as `portfolio`, upload the same files, and enable **Settings → Pages → Deploy from a branch → main → /(root)**. The URL will be `https://<YOUR-GITHUB-USERNAME>.github.io/portfolio/`.

GitHub Pages publishes static files. The site is public on the internet, so do not commit private information, access tokens, or personal documents you do not want public. Publishing can take several minutes after saving the settings.

Official guide: https://docs.github.com/en/pages/quickstart
